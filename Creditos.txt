PS1/2 — version 4.12

Interface inspired by the PlayStation 2 menu. Original vector background.
P1 marker: original vector drawing, with arcade type and a cursor tip.
Conceptual reference for P1 / Player 1, without copying images or fonts:
https://en-americas-support.nintendo.com/app/answers/detail/a_id/41237/p/1095
The console startup GIFs are included locally, with no audio.
The same GIFs loop in the preview of the preselected console
for mouse, keyboard or controller, without opening the emulator; with Reduce Motion,
the preview is static. Moving the pointer off the card keeps the selected preview.
The launcher contains no BIOS files.
Navigation reference: official Sony manual, pages 31–32:
https://www.playstation.com/content/dam/global_pdc/en/corporate/support/manuals/ps2-docs/scph-90004/SCPH-90002CB_90003CB_PS2_UG_EN.pdf
